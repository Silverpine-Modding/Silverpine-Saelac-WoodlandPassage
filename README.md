# Woodland Passage

Configure which trees, fallen wood and rocks the player can pass through in Silverpine. Small trees, sticks, felled trees and small rocks are passable by default. Medium rocks can be enabled separately.

Requires Modding Tools 1.10.0 or newer. Open Woodland Passage in the inventory Mods tab to configure each obstacle type.

With Silverpine closed, extract the release ZIP into the game directory. The plugin DLL belongs in `BepInEx/plugins/WoodlandPassage/`.
